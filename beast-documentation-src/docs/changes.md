# Changing or cancelling a request

| Current situation | How to proceed |
| --- | --- |
| Submitted but not yet advisor-approved | Contact an administrator to cancel or correct it; the queue self-service controls are not yet available |
| Advisor-approved and still in the automatic queue | Use your authorized private monitoring link to modify eligible resources/time or select **Cancel request** |
| Alternative window offered | Request the offered window through private monitoring; availability is checked again |
| Already scheduled in the GPU Panel | Contact an administrator to cancel or release the actual reservation |
| Exclusive machine request | Contact an administrator; it is not handled by the automated queue controls |

Cancelling a **queued request** marks it cancelled in the tracker and removes it from automatic scheduling. It **does not cancel an existing GPU Panel reservation**. Do not assume that a button labelled “Cancel request” releases resources that have already been reserved.

If a student no longer needs an allocation, they should notify the administrator promptly so resources may be released or reassigned.
