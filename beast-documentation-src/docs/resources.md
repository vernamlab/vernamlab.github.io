# Resource categories

BEAST distinguishes routine computing from experiments that may affect the shared environment.

| Category | Intended use | Scheduling path |
| --- | --- | --- |
| Light | Short or relatively modest computing tasks | Advisor review, then automatic scheduling when eligible |
| Standard | Typical training, analysis, and development | Advisor review, then automatic scheduling when eligible |
| Intensive | More demanding research workloads | Advisor review, then automatic scheduling when eligible |
| Security / Side-Channel, specific allocation | Specialized experiments using a defined share of resources | Advisor review, then automatic scheduling when eligible |
| **Security / Side-Channel, entire machine** | Experiments that require an uninterrupted, exclusive machine window | **Advisor review followed by manual administrator handling** |

A request for exclusive use is **not** automatically scheduled. Selecting a security workload does not, by itself, require manual administration when only a specific allocation is requested.

All requests must identify resource requirements accurately. Availability is checked when a reservation is created; an earlier estimate or suggestion is not a confirmed allocation.
