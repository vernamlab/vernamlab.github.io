# Help and support

## Before contacting the administrators

Check your reservation status and the instructions associated with your ticket. If you have received a confirmed reservation, use the restricted operational guide provided to you; connection and privileged system details are not part of the public website.

When reporting a problem, provide your ticket identifier, your registered email, the approximate requested time, and a concise description of the issue. Do **not** post passwords, private link tokens, datasets, or system configuration details in public discussions.

## Common issues

| Issue | Recommended action |
| --- | --- |
| No confirmation email | Check the registered address and spam folder; request help if the ticket status is unclear |
| Advisor approval pending | Ask the advisor to review the ticket |
| No resources assigned | Check the queued-request status and any suggested changes |
| Reservation exists but setup instructions are missing | Request a fresh private status link or contact an administrator |
| Job interrupted or environment unavailable | Stop the affected work, save available results, and contact an administrator |

The public guide intentionally omits server addresses, network paths, system configuration, and privileged access steps. Authorized users receive those details through a restricted channel.
